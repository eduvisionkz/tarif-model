# Тариф таңдау моделі — PWA

Орнатылатын веб-қолданба. Ол «Ауылдағы байланыс: ұялы байланыс тарифін таңдаудың математикалық моделі» зерттеу жұмысына негізделген.
Авторы — Аманжолова Кәусар, 8 «А» сыныбы, «Ш. Уәлиханов атындағы орта мектебі» КММ. Ғылыми жетекшісі — Қайратқызы Назерке.

Қолданба серверсіз жұмыс істейді. Есептеу, тариф базасы, профильдер мен шығын тарихы пайдаланушының құрылғысында сақталады.

## Құрамы

```
index.html              — қолданба қабығы
css/app.css             — стильдер (жарық/қараңғы тақырып)
js/tariffs.js           — ТАРИФ БАЗАСЫ (жаңартуды осы жерден жасайсыз)
js/engine.js            — модель: K = min(Gт/G, Mт/M, Sт/S, Nт/N), баға, бюджет, желі, 12 төлем, тарих
js/storage.js           — құрылғыда сақтау, схема нұсқасы, сақтық көшірме
js/app.js               — экрандар, экспорт (CSV, басып шығару), PWA орнату/жаңарту
sw.js                   — service worker (желісіз жұмыс)
manifest.webmanifest    — PWA манифесті
icons/                  — 192, 512, maskable 512, apple-touch, favicon.svg
vercel.json             — Vercel тақырыптары (sw.js кэштелмейді)
.nojekyll               — GitHub Pages үшін
tests/engine.test.cjs   — зерттеудегі есептермен тексеру (Node.js)
tests/ui.test.cjs       — браузердегі әрекеттер (Playwright)
tests/update.test.cjs   — жаңартуда деректер өшпейтінін тексеру
VERIFICATION.md         — тексеру нәтижелері және табылған қайшылықтар
```

Құрастыру (build) қажет емес: файлдар сол күйінде жарияланады. Барлық жол салыстырмалы (`./`), сондықтан қолданба GitHub Pages-тегі ішкі қалтада да (`/repo-name/`) жұмыс істейді.

## Жергілікті іске қосу

```bash
cd tarif-pwa
python3 -m http.server 8080
# браузерде: http://localhost:8080
```

Service worker тек HTTPS немесе `localhost` арқылы жұмыс істейді. Файлды тікелей (`file://`) ашсаңыз, есептеу жұмыс істейді, бірақ орнату мен желісіз режим болмайды.

## Vercel-ге жариялау

**Сайт арқылы (бағдарламасыз):**
1. https://vercel.com сайтына кіріп, GitHub арқылы тіркеліңіз.
2. Жобаны GitHub репозиторийіне жүктеңіз (төмендегі GitHub Pages бөлімінің 1–2-қадамдары).
3. Vercel-де: **Add New → Project**, репозиторийді таңдаңыз.
4. **Framework Preset: Other**. Build Command бос қалады. Output Directory: `.` (түбір).
5. **Deploy** басыңыз. Сілтеме `https://<атау>.vercel.app` түрінде болады.

**Командалық жолмен:**
```bash
npm i -g vercel
cd tarif-pwa
vercel          # алғашқы баптау
vercel --prod   # жариялау
```

## GitHub Pages-ке жариялау

1. GitHub-та жаңа репозиторий ашыңыз, мысалы `tarif-model` (Public).
2. **Add file → Upload files** арқылы архивтің *ішіндегі* барлық файл мен қалтаны жүктеңіз. `index.html` репозиторийдің түбірінде болуы керек; `.nojekyll` файлын да жүктеңіз.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch: `main`, қалта: `/ (root)` → **Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://<пайдаланушы>.github.io/tarif-model/`.

## Android-қа орнату (APK қажет емес)

1. Жарияланған HTTPS сілтемесін Android телефонында **Chrome** арқылы ашыңыз.
2. Бетте «Орнату» батырмасы шықса, соны басыңыз. Шықпаса, Chrome мәзірін (⋮) ашып, **«Қолданбаны орнату»** немесе **«Негізгі экранға қосу»** тармағын таңдаңыз.
3. Иконка қолданбалар тізімінде пайда болады. Қолданба бөлек терезеде, мекенжай жолағынсыз ашылады.
4. Бір рет интернетпен ашқаннан кейін қолданба желісіз де жұмыс істейді.

Ескерту: мен орнатуды нақты Android құрылғысында тексерген жоқпын. Тексерілгені: Chromium-дағы манифест, service worker, желісіз қайта ашылу және жаңарту (VERIFICATION.md).

## Тариф деректерін жаңарту

1. `js/tariffs.js` файлындағы тарифтің жазбасын өзгертіңіз: `price`, `gb`, `minutes`, `promo`, `checked` (жаңа тексеру күні), `source`.
2. Ресми бетте сан көрсетілмесе, өріске `null` жазыңыз. Ол «нақтылау қажет» деп көрсетіледі. `null`-ды 0-ге немесе үлкен санға ауыстырмаңыз.
3. `TARIFF_BASE.version` пен `checkedLabel` мәндерін жаңартыңыз.
4. **Міндетті:** `sw.js` ішіндегі `CACHE_VERSION` мәнін өзгертіңіз (мысалы, `tarif-model-v1.0.1`). Сонда орнатылған қолданбада «Жаңа нұсқа дайын» хабары шығады.
5. `node tests/engine.test.cjs` командасын іске қосыңыз. Баға өзгерсе, кейбір сценарийдің күтілетін жауабы да өзгеруі мүмкін.

## Деректер және жаңарту

- Профильдер, шығын тарихы, желі белгілері және соңғы форма `localStorage`-те `tarifModel.*` кілттерімен сақталады.
- Service worker тек қолданба файлдарының кэшін ауыстырады. Ол сақталған деректерге тимейді.
- Жаңа нұсқа өздігінен қосылмайды: пайдаланушы «Жаңарту» батырмасын басқанда ғана іске қосылады.
- Схема өзгерсе, `js/storage.js` → `migrate()` ішіне түрлендіру қадамын қосыңыз. Ескі деректі жоймаңыз.
- «Профильдер → Сақтық көшірме» бөлімі профильдер мен тарихты JSON файлға сақтайды және басқа құрылғыда қайта жүктейді.
